### Hi, I'm pegton 👋

I build small, honest data tools: public data only, no logins, no cookies, no CAPTCHA tricks. Each one is tested on real pages and documented with measured numbers.

**Open source**
- 🖼️ [**shiftdiff**](https://github.com/Zapparelo/shiftdiff): a visual diff for screenshots that ignores layout shifts. With a 77 px banner on bbc.com, a pixel-by-pixel diff reports 26 % of the page changed; shiftdiff reports 0.47 %.
- 🔔 [**n8n-website-change-monitor**](https://github.com/Zapparelo/n8n-website-change-monitor): a free n8n workflow that e-mails you a red-marked diff image when a page really changes.
- ☀️ [**post-eeg-solar-germany**](https://github.com/Zapparelo/post-eeg-solar-germany): open data (CC BY 4.0) on 417,003 German PV systems whose EEG feed-in tariff ends 2020–2028, by district. From the Marktstammdatenregister.
